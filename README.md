# Nocturne — Piano de lumière

Jeu de piano dans le navigateur : les notes tombent en lumière, tu les joues au clavier d’ordinateur (AZERTY, QWERTY, QWERTZ, du 60 % au 100 %) ou sur un clavier MIDI.

- **Morceaux** : mode Apprendre (le morceau attend la bonne note), Défi (rythme, score, étoiles) et Écoute ; vitesse, boucles, main gauche / droite.
- **Leçons** pour débuter, **entraînements** (gammes, arpèges, accords, oreille, lecture de notes).
- **Jeu libre** avec nom des accords, enregistrement et export MIDI.
- **Import de fichiers MIDI** par glisser-déposer.
- Progression, calendrier de pratique et succès, enregistrés dans le navigateur.

Ouvrir `index.html` suffit : aucun serveur, aucune installation.
